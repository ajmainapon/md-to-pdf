## Core Capabilities

| Capability | Details |
| :--- | :--- |
| **Markdown & GFM Tables** | Headings, task lists, footnotes, callout alerts (`[!NOTE]`, `[!IMPORTANT]`), and academic tables. |
| **LaTeX & KaTeX Math** | Supports `$$...$$`, `$...$`, `\[...\]`, `\(...\)`, ChatGPT `[ ... ]` / `( ... )` math, and multi-line matrices (`bmatrix`, `pmatrix`, `cases`, `aligned`). |
| **Physics, Units & Chemistry** | Native support for `physics` (`\dd`, `\dv`, `\pdv`, `\bra`, `\ket`), `siunitx` (`\SI`, `\si`, `\num`), and `mhchem` (`\ce{...}`, `\pu{...}`). |
| **Smart Clipboard Paste** | Copying rendered math directly from ChatGPT, Claude, Gemini, or Wikipedia extracts underlying `<annotation encoding="application/x-tex">` LaTeX automatically. |
| **Photos & Local Images** | Supports local paths (`./images/setup.png`) via 1-click attachment or multi-file drag-and-drop, Obsidian embeds (`![[photo.png\|420]]`), custom width sizing (`![Caption\|420](...)`), figure captions, and `Cmd+V` screenshot paste. |
| **Mermaid Diagrams** | Renders `flowchart`, `sequenceDiagram`, `stateDiagram-v2`, `classDiagram`, and `erDiagram` blocks into vector SVGs. |
| **Page Layouts** | Switch between **Single Column**, **IEEE 2-Column (Paper)** (with auto-spanning wide tables and matrices), and **Exam Cheat-Sheet (Dense 2-Col)**. |
| **5 Academic Themes** | *Modern Editorial (Blue)*, *Nordic Teal & Navy (STEM)*, *Academic Paper (LaTeX Serif)*, *Oxford Navy & Terracotta*, and *Minimalist Mono*. |
| **100% Client-Side** | All parsing, math rendering, and PDF generation run locally in the browser with zero server uploads or watermarks. |
